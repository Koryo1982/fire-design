積立フェーズ — FIREまで

あなたがコントロールできる変数

給与から証券口座へ回す年間積立額です。Coast FIRE到達後は積立0が前提（設計図と同じ）。市場リターンとは別物として考えます。

運用前提 — 市場・3層構造

市場がコントロールする変数（設計図のA/B/C層）

成長層（C・インデックス）はトータルリターン（配当再投資込み）。安定層（B・高配当）は配当＝現金＋値上がりを分離。配当はFIRE後は生活費に充当、積立期間中は再投資されます。層の割合は設計図の資産配分（A —% / B —% / C —%）を使用。

計算の前提・無料／会員の境界（予定）

計算の前提

  • 成長層・安定層のリターンは幾何ブラウン運動（対数正規）で年次生成。生活防衛層は固定金利です。
  • 資産は設計図の3層（A/B/C）比率で分割。成長層はトータルリターン、安定層は配当現金＋値上がり、生活防衛層は金利のみ。
  • 安定層の配当は積立期間中は再投資、FIRE後はCoast収入・年金と合わせて生活費から差し引き（売却取崩しを減らす）。
  • 「世帯の年間生活費」は夫婦の暮らしのベース（現在価値）。子ども関連はライフイベントタブで上乗せします。
  • 教育費は子どもごとの月額×残り年数＋入学金を、父の年齢に展開して毎年の特別支出に加算します。
  • 支出はインフレ率で毎年複利増加。突発支出は指定年齢に、定期支出は初回年齢以降・周期ごとに加算します。
  • 年金開始後は、Coast収入・配当と合わせて必要取崩し額から相殺します（いずれもインフレ連動）。
  • 税金は取得元本を追跡し、取崩し額のうち利益部分に20.315%を課税した上で手取りが必要額に一致するようグロスアップします。
  • ガードレール：判定・調整の対象は「世帯の年間生活費」のみ。突発・定期の特別支出・税社保スパイク・医療介護費は固定費として上乗せします。
  • FIRE翌年に前年給与ベースの住民税・健康保険料（税金・社保スパイク）を一時費用として加算できます。
  • 高齢期は指定年齢以降の年間医療・介護バッファと、特定年齢での介護一時金を自動加算できます。
  • 本シミュレーションは将来の成果を保証するものではありません。

無料／会員の境界（予定）

  • 無料 基本5項目・積立・運用前提・取り崩し内訳・成功確率とグラフ
  • 会員 教育費フル・支出イベント・詳細設定（ガードレール・年金・税金・医療介護など）
  • 会員機能はラベルのみ先行表示中。note メンバーシップ開始まではすべて無料です。
